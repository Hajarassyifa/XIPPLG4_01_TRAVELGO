## About Laravel

Laravel is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable and creative experience to be truly fulfilling.

## Learning Laravel

Laravel has extensive [documentation](https://laravel.com/docs) and video tutorials.

In addition, [Laracasts](https://laracasts.com) contains thousands of video tutorials. Boost your skills by digging into our comprehensive video library.

You can also watch bite-sized lessons with real-world projects on [Laravel Learn](https://laravel.com/learn), where you will be guided through building a Laravel application from scratch while learning PHP fundamentals.
